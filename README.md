# JAVA POO 

Projeto desenvolvido em Java durante os estudos de Programação Orientada a Objetos.

## Sobre o projeto

O projeto simula um sistema simples de uma agência de viagens.

É possível cadastrar informações sobre transporte, hospedagem e destino, além de calcular o valor de um pacote de viagem considerando os dias de hospedagem, margem de lucro e taxas adicionais.

Também é feita a conversão do valor do pacote de dólar para reais de acordo com a cotação informada.

## Tecnologias

- Java
- NetBeans
- JDK 21

## Conceitos utilizados

- Classes e objetos
- Atributos
- Construtores
- Métodos
- Encapsulamento
- Getters
- Relacionamento entre classes
- Cálculos e retorno de valores

## Classes do projeto

**Transporte**  
Armazena o tipo e o valor do transporte.

**Hospedagem**  
Armazena a descrição da hospedagem e o valor da diária.

**PacoteViagem**  
Reúne as informações do transporte, hospedagem, destino e quantidade de dias. Também realiza os cálculos do pacote.

**Venda**  
Armazena os dados do cliente e da forma de pagamento e realiza a conversão do valor para reais.

**Main**  
Responsável pela entrada dos dados e execução do programa.
